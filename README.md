# HomeMate Handyman

Six-page static website build for HomeMate Projects.

Pages: Home, Services, Previous Jobs, Testimonials, About, Contact.

## Local preview
Run any simple static server in this folder, for example `python -m http.server 8080`, then open `http://localhost:8080`.

## Important
- This build is **not deployed**.
- The existing `HomeMate-Projects` repository was used only as a read-only source for branding/content and was not changed.
- Current project images/logo are referenced from the live `homemateprojects.com.au` site so the build can be reviewed without duplicating large binary assets. Before final cutover, copy those assets into this repository and change the image paths to local files.
- Contact form posts to the existing Formspree form ID already used by the current website.
- Calendly booking: https://calendly.com/omoore-homemateprojects/hire_a_handyman_for_an_hour
- Canonical URLs target homemateprojects.com.au for eventual replacement of the existing site.
