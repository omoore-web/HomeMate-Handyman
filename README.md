# HomeMate Handyman

Six-page static website build for HomeMate Projects.

Pages: Home, Services, Previous Jobs, Testimonials, About and Contact.

## Local preview

Run any simple static server in this folder, for example `python -m http.server 8080`, then open `http://localhost:8080`.

## Important

- This repository contains the new website code only. It does not alter the existing `HomeMate-Projects` repository.
- The site is not connected to or deployed on `homemateprojects.com.au`.
- The HomeMate Projects logo and optimised project images are stored locally under `assets/images`.
- The contact form posts to the existing Formspree form ID already used by the current website.
- Calendly booking currently uses `https://calendly.com/omoore-homemateprojects/hire_a_handyman_for_an_hour`.
- Canonical URLs target `homemateprojects.com.au` for an eventual approved replacement of the existing site.
- No automatic deployment workflow is included.
